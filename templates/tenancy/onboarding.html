Welcome to LabButler 👋

LabButler keeps your lab's inventory and purchasing in one place{% if lab %} — you are a member of {{ lab.name }}{% endif %}. These are the parts that matter for what you can do here.

{% comment %} Steps are chosen per member from their permissions (apps.tenancy.onboarding), so nobody reads about buttons they don't have. Numbering follows what's shown. {% endcomment %}
    {% for step in steps %}
  1. {% if step == "profile" %}

    {{ forloop.counter }} · Introduce yourself

    Set a display name so colleagues see your name instead of your email address in lists, comments, and emails.

    {% elif step == "find" %}

    {{ forloop.counter }} · Find things

    The Inventory holds every item in the lab. Search by name, CAS number, or the item ID printed on the container label — that ID never changes, so an old label always finds its record.

    {% elif step == "scan" %}

    {{ forloop.counter }} · Scan a label

    On your phone, open Scan and point the camera at a container's Data Matrix label to jump straight to the item.

    {% elif step == "request" %}

    {{ forloop.counter }} · Order things

    Need something the lab doesn't have? Raise a request — paste the product link from the shop and LabButler fills in what it can. The request moves through approval, ordering, and delivery; your dashboard shows where it stands.

    {% elif step == "approve" %}

    {{ forloop.counter }} · Approve requests

    New requests land in Requests to approve on your dashboard (and in your inbox — tune that in Account settings). Approve or reject them right there.

    {% elif step == "order" %}

    {{ forloop.counter }} · Place orders

    Approved requests you're responsible for — your own, or ones forwarded to you — show up under Requests to order. Mark them ordered once the order is out.

    {% elif step == "receive" %}

    {{ forloop.counter }} · Receive deliveries

    When a parcel arrives, open the request and Check in: the item lands in the inventory with its location, and you can print its label straight away.

    {% elif step == "sign" %}

    {{ forloop.counter }} · Sign order forms

    Orders through central purchasing need a signed order form. When one waits for you, it appears under Purchase orders to sign and you get an email.

    {% elif step == "setup" %}

    {{ forloop.counter }} · Set up your lab

    You manage this lab. The Getting started list on your dashboard walks you through locations, suppliers, budgets, importing your inventory, and inviting your team — including a join link people can use to ask for access.

    {% elif step == "rights" %}

    {{ forloop.counter }} · Know what you can do

    What you see is governed by the roles your lab manager gave you. If something mentioned in the docs is missing, check your effective permissions in Account settings — that page also tunes which emails LabButler sends you.

    {% endif %}
